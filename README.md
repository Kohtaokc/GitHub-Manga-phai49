##ตอนต่อไป: Ep.5-Dimension-Hunters

ในโลกคู่ขนานแรกที่เขาไปเยือน ทุกอย่างดูเหมือนจะเป็นฝันดี — บอสยังมีชีวิต เป็นนักกฎหมายที่เปี่ยมด้วยเมตตา น้องจิ้งจอกเองก็ไม่เคยเดินบนเส้นทางแก๊งใต้ดิน แต่ความสงบไม่ยืนยาว…

“ฆ่าเงาที่ทรยศ” — เสียงจากอีกจักรวาลหนึ่งสั่นสะเทือนในหัวเขา

บอสของโลกนี้ถูกจับโดยแก๊งสารเลวที่ล่องหนข้ามจักรวาล พวกมันกำลังรวบรวม “บอสจากทุกโลก” เพื่อสร้างอำนาจเหนือมิติ — และแผนปลุกจิตมืดในจักรวาลทั้งหมด

จิ้งจอกออกตามหา “ตัวเองจากโลกอื่น” — รวมพันธมิตรเงาที่เข้าใจความเจ็บปวดเช่นเดียวกัน

มีทั้งจิ้งจอกที่ยังไว้ใจบอส... และจิ้งจอกที่กลายเป็นศัตรูของทุกสิ่ง

ในที่สุด พวกเขาก็รวมพลังบุกไปยัง “Nexus Zone” — ศูนย์กลางที่รวบรวมบอสจากทุกโลกเพื่อพิธีกรรมครั้งสุดท้าย

เมื่อประตูเปิดออก เขาเผชิญหน้ากับ “ตนเองในโลกมืดสุดขั้ว” — น้องจิ้งจอกที่ไม่เคยเสียใจ ไม่เคยรักบอส และไม่เคยเป็นมนุษย์

“จะยอมถูกลิขิตอีกไหม... หรือจะเขียนโลกขึ้นมาใหม่ด้วยมือเราเอง?”
